# Мониторинг состояния файлов

Консольное приложение на C++ с использованием Qt для отслеживания изменений файлов (создание, удаление, изменение размера).

---

## 1. Постановка задачи

Написать программу с консольным интерфейсом, которая выполняет слежение за выбранными файлами.

**Требования к реализации:**
- Язык: C++
- Использование **сигнально-слотного соединения** 
- При возникновении изменения состояния наблюдаемого файла (возникновение события), необходимо выводить на экран соответствующее сообщение.
- Отслеживание изменений: создание, удаление, изменение размера

---

## 2. Предлагаемое решение

### 2.1 Общая идея

1. Чтение пути к файлу-источнику
2. Валидация файла (существует, .txt формат)
3. Загрузка списка файлов для наблюдения
4. Настройка обработчиков сигналов (логгер)
5. Бесконечный цикл мониторинга:
  - Проверка изменений файла-источника
  - Проверка состояния наблюдаемых файлов
  - Вывод в консоль уведомления, если произошло какое-либо событие
  - Задержка 2 секунды

### 2.2 Структура решения

Решение основано на следующих классах:

#### 2.2.1 Класс ILogger (интерфейс)

Абстрактный базовый класс, определяющий контракт для всех классов логирования. Обеспечивает возможность замены реализации логирования без изменения остального кода.

#### 2.2.2 Класс ConsoleLogger 

Реализует интерфейс ILogger. Предназначен для вывода сообщений в консоль.

#### 2.2.3 Класс ITimer (интерфейс)  

Абстрактный базовый класс, определяющий контракт для классов задержки. Позволяет заменить реализацию таймера.

#### 2.2.4 Класс SecondsTimer

Реализует интерфейс ITimer. Использует std::this_thread::sleep_for для создания задержки.

#### 2.2.5 Класс Nabludatel (основной класс наблюдателя)
Основной класс программы, отвечающий за мониторинг файлов. Предназначен для хранения списка отслеживаемых файлов, проверки состояния каждого файла, генерации сигналов при обнаружении изменений

Сигналы класса:
- fileCreated(const QString& path) — файл создан
- fileDeleted(const QString& path) — файл удален
- sizeChanged(const QString& path, int oldSize, int newSize) — размер изменен

## 3. Инструкция пользователя

### Зависимости  

| Название | Версия |
|----------|--------|
| Qt | Qt 5.15.18 |
| C++ compiler | C++11 |

### Формат файла-источника
Файл-источник должен быть в формате .txt и содержать пути к отслеживаемым файлам, каждый путь с новой строки:

/Users/user/Documents/file1.txt
/Users/user/Documents/file2.pdf
C:\Users\user\Desktop\file3.docx

### Использование
Программа работает в интерактивном режиме через консоль:

1. Ввести путь к txt-файлу со списком отслеживаемых файлов

2. Программа начнет мониторинг и будет выводить сообщения об изменениях

## 4. Тестирование

### Входные данные - путь до txt файла

### Тестирование случаев для файла-источника

**Случай 1**: файл не txt формата
Результат: Программа завершается с сообщением об ошибке

**Случай 2**: файла по переданному пути не существует
Результат: Программа завершается с сообщением об ошибке

**Случай 3**: файл пустой
Результат: Наблюдателю передается пустой список, предполагается, что пользователь может добавить файлы в дальнейшем

**Случай 4**: файл содержит пути до директорий
Результат: Такие пути игнорируются

### Тестирование случаев для состояний файлов

**Случай 5**: Файла не было - файл был создан
Результат: Выводится сообщении о том, что файл был создан

**Случай 6**: Файл был - файл удалили
Результат: Выводится сообщении о том, что файл был удален

**Случай 7**: Файл был - файл поменял размер
Результат: Выводится сообщении о том, что файл был изменен, выводятся старый и новый размеры
